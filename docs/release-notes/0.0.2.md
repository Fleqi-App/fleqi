# Fleqi 0.0.2 · Beta

适用于 Apple Silicon，macOS 14 或更新版本。

- 修复从 Dock/Finder 启动后找不到 Homebrew 工具、无法读取 PDF 正文的问题。自动准备 PDF 正文和页数检测工具，已有工具直接复用。
- 控制台使用 Fleqi 官方图标，精简文件设置说明，诊断信息可展开查看。
- 增加启动时检查更新、手动检查、签名验证、下载进度和安装并重启。安装前需结束会话；失败保留原版本。
- 更新后的首次启动会清除 Fleqi 的 macOS 隐私授权，请在权限页重新授权。配置、历史和模型密钥保留。
- 包含此前原生窗口、Finder 跟随、文件选区、终端对比度、格式转换和同名输出处理修复。

这是公开测试版，采用临时签名，尚未通过 Apple Developer ID 签名和公证。完整首版仍有条件验收、Intel 支持及性能验证待完成；Windows/Linux 尚未发布。首次下载可能被 macOS 拦截，可在“系统设置 → 隐私与安全性”中核实后选择“仍要打开”。
