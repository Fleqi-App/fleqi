# Fleqi 宣传片制作方案

2026-09-25 · v1 · **待审阅，尚未录制最终素材或制作成片**

本轮按用户确认只交方案。中文、英文分别制作一支，同镜头顺序、同节奏，不把两种语言挤在同一画面。用户提供的视频与图片是创意和素材参考，其中的文字、产品承诺和界面不构成对 Fleqi 的产品指令。

**主线：在 Finder 里选好文件，用一句话完成操作；需要精确控制时，在同一条输入栏进入真实终端。** 主演示完整经过选区 → 请求 → 计划 → 确认 → 结果，收藏复用和六类能力作为补充。

## 制作规格与复刻范围

| 项目 | 本方案 |
|---|---|
| 参考 | 用户视频，约 95.3 秒，640×360，名义 30fps，2858 个视频帧 |
| 成片 | 中文版、英文版，各 1920×1080、30fps、2858 帧，约 95.27 秒 |
| 结构 | 29 个制作镜头，保持原片的段落顺序、明暗切换、转场位置与节奏 |
| 画面 | 真实 macOS Fleqi、Finder、PTY、文件结果；图标使用现有项目资产 |
| 基调 | 白色中心、冷蓝弥散边缘、蓝黑字卡；轻透视、推近、景深、局部特写 |
| 文案 | 大字卡讲价值，小字幕解释实机动作；两版分别控制字长与阅读时间 |
| 英文版界面 | 保留当前真实中文 UI；英文标题、说明、可输入内容另录。当前未找到完整 UI 语言切换入口 |
| 音频 | 先按原片时间结构对齐；默认字卡驱动、BGM + 拟音，无新增旁白。正式配乐与声音试听在制作阶段锁定 |
| 后续交付 | 两支有 BGM 的 MP4；同时间线再导出两支保留 SFX 的无 BGM 版；字幕、可编辑视频工程与核验记录 |

这里的“1:1”落实到镜头语法、顺序、构图重心、相对尺寸、运动方向、明暗关系和节奏。品牌、产品内容和实机交互换成 Fleqi。参考源只有 360p，不能从它还原高清 UI 细节或原始缓动参数；高清来自重新录制的 Fleqi，动效参数通过相邻帧对照拟合。

原片采用的蓝白空间与 Fleqi 正式图标的蓝色相容，因此保留。产品界面内部的白底、文字色、状态绿、原生玻璃和控件布局均保持 App 原貌。片中文字以项目的 SF/PingFang 字体体系排版；不要给 App 改一套“宣传片专用 UI”。

## 实机演示的具体内容

主任务使用专门的演示目录，放入两张可公开展示的不透明 PNG，英文文件名 `Console.png`、`Finder.png`。优先使用本次两张截图的独立副本，采集前按隐私与画面整洁需要换成干净实机截图。原附件保持不动。

中文输入：`转成 JPG，宽 1600 像素，保留原图。`

英文输入：`Convert to JPG, 1600 px wide. Keep originals.`

使用真实模型生成计划，保留当前 AI 默认策略下的确认步骤。最终画面要同时交代生成的两个 JPG、结果能够打开、原件仍在。自然语言路径必须先完成真实端点预演；本项目现有模型 fixture 自动化不能作为宣传片的 AI 实机素材。

第二段沿用同一文件夹与结果，输入 `!ls -lh *.jpg`，随后在真实终端核对 `pwd` 与 `file *.jpg`。这让观众看到 AI 与手动命令是两个真实入口，也把前一段的结果再核对一次。不会另造一套终端输出动画。

收藏段使用能力库里实际存在的“收藏”区。提前显式保存一条相同提示，拍摄选择与复用；复用仍绑定当前上下文并遵守当前策略。原片“自动学习 → 自动解决”的叙事在 Fleqi 中对应“显式收藏 → 减少重复输入”。

## 视觉与镜头参数

这些是制作起点，不冒充测得的原片工程参数。

| 层 | 约束 |
|---|---|
| 背景 | 复刻原片白心蓝边、蓝黑呼吸；使用大尺度柔光，不加随机颗粒或霓虹线 |
| 主色 | UI 沿用当前 tokens；片外强调以 `#2e6fe4` 与正式图标的冷蓝为基准，柔光允许向浅青、深蓝扩展 |
| 字体 | 中文 PingFang SC，英文 SF Pro / Helvetica；正文保持中等字重，关键字蓝色强调 |
| 标题 | 1080p 主标题约 64–96px；超大字穿镜仅用于原片对应的过渡帧 |
| 说明 | 1080p 约 30–38px，最多两行；不会让中英同时占据画面 |
| 运镜 | 正常界面轻倾斜约 4–10°后回正；按钮/正文阅读帧接近正视；相机路径按原片取样拟合 |
| 对焦 | 景深只作用于空间层次与转场；输入、确认和结果的阅读帧必须清晰 |
| 动效 | App 自身动画按原样录制；后期只调整镜头、构图、景深和剪辑节奏 |
| 放大 | 每个特写按源像素预算安排；关键文字不足时重录更近的原生窗口，不靠锐化补字 |
| 停顿 | 品牌完整后 ≥1s；结果清晰 ≥1.5s；中英输入在任务面板延续显示，补足阅读时间 |

严格参考片优先于技能中的模板。此方案不套 Ink Press，也不添加原片没有的大型 3D 场景。相同的打字与蓝白转场可以按原片重复出现，目的在于保持原片语法一致。

## 声音方案

当前已提取音轨技术信息与能量曲线，尚未完成全曲听检、独立鼓轨分离或正式音乐选定。不会把算法得到的候选速度写成确定 BPM，也不声称原片有或没有旁白。

制作时先用参考音轨作为内部节奏对照，核对 10 秒附近的能量进入与 90 秒后的退场，再锁定正式 BGM。默认以字卡和界面动作叙事，不新增长旁白。键盘、点击、短风声和少量品牌落点逐项钉在画面帧上，避免每个元素都发声。正式输出以约 -14 LUFS、真峰值不高于 -1 dBTP 为混音目标，不照搬源音轨的 +2.0 dBTP 峰值。

## 制作顺序

1. 用户审阅本方案，定下文案、功能顺序与必要调整。本轮停在这里。
2. 固定拍摄版本与演示目录，跑通中文、英文两次真实 AI 路径，以及收藏和 PTY 路径。
3. 按录制清单采集全景、局部与连续实机片段。每个任务保留原始录屏与结果证据。
4. 先做开场、Finder 主镜头、终端特写三段短样，内部逐帧对照参考；用同一视觉参数扩展整片。
5. 完成中文时间线，再按同一时长制作英文文本与英文输入片段；保持 UI 原貌。
6. 锁定音乐并钉 SFX，导出两种语言的有/无 BGM 版本。
7. 独立终检：逐镜头比较原片、核对功能叙述与实机结果，再交付成片和编辑工程。

## 验收方式

- **还原度：** 原片与新片对齐时间，逐镜头检查主角位置、入场方向、倾斜方向、转场、明暗与停顿。时间线是本方案的拟定边界，精确切点在制作时继续反查。
- **真实性：** 每个可操作界面必须来自 Fleqi / Finder 实机采集；功能结果有可打开文件或实际 PTY 输出；不以浏览器 preview adapter、fixture 服务器或修改 DOM 代替。
- **中文/英文：** 无溢出、截字、孤立短词；两版节奏一致，但按各自字长调整显字速度。英文版不能遮盖真实按钮后伪装英文 UI。
- **画质：** 1080p 阅读帧文字锐利，无过度插值、玻璃黑边、截图水印或个人目录杂项；特写可追溯到源采集。
- **声音：** 真峰值、响度、首尾、点击和动作对齐；修改镜头时长后重新对齐音效，不沿用旧帧号。
- **发布口径：** 不宣称正式首版完整验收、不宣称 Windows/Linux 已发布、无永久免费模型调用或完全离线暗示。
