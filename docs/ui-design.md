## 1. 决策、参考与适用边界

### 1.1 已锁定的产品交互与设计默认值

1. 主操作栏就是日常输入条，同一输入位置支持 AI 与手动终端模式。默认使用 AI；首个非空半角 `!` 进入手动终端模式，`!` 及后续字符全部变绿，提交时剥离这个模式标记。
2. `activation` 有 `manual`、`followFinder` 两种模式。默认 `manual`；用户可以开启随 Finder 自动显示。`followFinder` 不要求已配置快捷键；`barEnabled=false` 时两种模式都不显示操作栏。
3. 操作栏当前可见会话跟随活动 Finder 目录。终端忙碌或存在未提交编辑行时，目录同步延后；显示真实目录与待切换目录，不能伪装已经切换。
4. 会话选择器包含活跃会话与历史。置顶影响整个会话及其历史在列表中的排序，不改变原生窗口层级；删除按钮位于图钉左侧。
5. 主动隐藏使用持久设置 `hideBehavior=keepAll|endAll`。`keepAll` 保留全部后台会话；`endAll` 结束全部会话、关联 AI 任务和 PTY。保留后再次手动显示默认新建会话，旧会话只能从列表主动切回。
6. Finder 移动、失焦等系统原因造成的临时隐藏不执行 `hideBehavior`；恢复时继续原会话。用户主动隐藏后暂停自动重现，直到显式再次显示或更改唤起模式。
7. AI 执行策略只有 `yolo`、`readOnlyAutoConfirmChanges`。它们只约束 AI；手动 `!` 提交及终端面板输入按普通终端直通。
8. 交互终端支持持续会话、命令输入与交互程序。一次性 AI 任务与 PTY 使用不同执行通道，并关联同一个会话。
9. 六类 30 项基础文件能力与能力目录中的 105 项、10 类操作意图全部属于首版；模型配置、工具安装、规则、收藏、多会话和终端也属于首版。文件转写、字幕和 OCR 属于首版；实时语音为下一版，不在首版界面保留假按钮。
10. 用户配置自己的模型 API；不出现订阅、试用、激活、强制账号登录或自营代理流程。

`manual`、`keepAll`、`readOnlyAutoConfirmChanges`、首个非空半角 `!` 的识别方式为本项目采用的设计默认值；不得在变更记录中称为视频测量值。后文新增尺寸、排序、提示时长等也明确作为设计默认值。

## 2. 信息架构与界面登记

### 2.1 界面层级

- **操作栏层：**日常输入、模式、上下文、建议、任务状态与会话入口。自动显示不主动抢键盘焦点。
- **锚定面板层：**会话选择、当前会话任务列表/详情、建议浏览、模型选择、终端。每个操作栏同一时刻最多一个主要锚定面板；任务列表与详情属于同一面板的不同路由。
- **结果气泡层：**短结果、复制和回应，绑定具体 Run。任务详情打开时收起同一 Run 的气泡，避免重复信息。
- **控制台窗口层：**工作区、设置、能力、规则、收藏、模型、工具、权限和关于。默认隐藏，用户通过菜单或操作栏入口打开。
- **确认层：**删除本地记录、清空历史、导入覆盖等应用级确认。AI 文件改动的批准在任务详情中完成，不重复弹出第二个相同确认。

这里的“层”表示交互职责，不要求每一层对应不同原生窗口。窗口实现与坐标边界由[架构](architecture.md)定义。所有弹层退出后立即停止接收点击和键盘，视觉离场不得延长可操作期。

| 界面 ID | 名称与入口 | 首版内容 | 必备状态 |
|---|---|---|---|
| `UI-COMPOSER` | 主操作栏；热键或自动显示 | AI/终端输入、目录、建议、任务、会话、策略、隐藏 | 禁用、隐藏、暂隐、输入、提交、目录等待、目录错误 |
| `UI-SESSION-SELECTOR` | 右侧会话控件 | 活跃/历史列表、搜索、置顶、删除、切换、新建/继续 | 空、加载、切换中、结束中、删除失败 |
| `UI-RUN-LIST` | 任务指示器 | 当前会话 Run 列表、过滤、定位、清空已完成 | 空、运行中、待批准、失败、取消、历史只读 |

### 2.3 控制台导航

保留旧工作区的双栏结构、可折叠侧栏和底部设置入口。侧栏组织如下：

| 分组 | 导航 | 内容边界 |
|---|---|---|
| 工作区 | 概览、会话与任务、能力、收藏、规则、终端 | 同一新应用的数据；终端为真实会话入口 |
| 连接与工具 | 模型与 API、工具、权限与自检 | 配置用户模型及本机执行条件 |
| 底部 | 关于与更新、设置 | 不保留账号头像、“未登录”或 GitHub 登录文案 |

概览展示实际会话/任务状态与六张能力卡片，卡片可进入对应能力视图；“能力”页面包含完整十类目录。这样保留截图中的六卡视觉，同时消除标题和内容路由不一致。底部状态显示真实状态，例如“操作栏已启用 · 手动唤起”或“自动显示已暂停”，不以“界面预览”作为产品状态。

关闭控制台只关闭该窗口；不调用主操作栏的隐藏策略，不结束任务。退出 Fleqi 是独立的应用退出动作，结束活动任务和 PTY，并保留已落盘历史。

## 3. 显示、会话与目录的独立状态

### 3.1 状态轴

| 状态轴 | 表示 | 不能替代的含义 |
|---|---|---|
| `barEnabled` | 操作栏功能是否启用 | 不等于会话是否结束 |
| `activation` | `manual` 或 `followFinder` | 不等于当前是否有焦点 |
| `visibility` | `userHidden`、`visible`、`temporarilyHidden`；未启用/未开始显示另由设置和显示周期判定 | 不等于 PTY/AI 任务是否存活 |
| `autoShowSuppressed` | 主动隐藏后暂停自动显示 | 不能被 Finder 普通选区事件清除 |
| `hideBehavior` | `keepAll` 或 `endAll` | 只用于用户主动隐藏 |
| `activeSessionId` | 当前显示的会话 | 后台会话不随当前 Finder 改目录 |
| `sessionState` | `active / ending / ended / failed`；创建中的界面请求另行表示 | 已结束不等于本地历史已删除 |
| `directorySync` | `synced / pending / syncing / failed` | 当前 Finder 目录不等于 PTY 已完成 `cd` |
| `inputMode` | AI 或手动终端 | 不能从 AI 执行策略推断 |
| `panelRoute` | 当前锚定面板及其子页面 | 面板关闭不取消任务 |

UI 消费宿主快照与结果，不从窗口可见性、输出文本或 spinner 自行推断这些状态。

### 3.2 自动显示与恢复场景矩阵

| 条件或事件 | 操作栏行为 | 会话行为 | 焦点 |
|---|---|---|---|
| `barEnabled=false` | 保持隐藏；入口引导启用 | 用户从启用改为禁用时按主动隐藏策略处理会话；已禁用状态不重复处理 | 不抢焦点 |
| `manual`，未配置/注册快捷键 | 不自动显示；手动入口提示先配置有效快捷键 | 不自动创建会话 | 配置页由用户主动打开 |
| `manual`，已配置快捷键 | 等待用户手动显示 | 显示时新建，除非用户从列表明确选择会话 | 热键显示后聚焦输入 |
| `followFinder`，无快捷键，有有效目录与权限 | 可自动显示 | 首次有效上下文新建会话 | 不抢 Finder 焦点 |
| `followFinder`，已有可见会话，活动目录变化 | 保持同一操作栏 | 复用当前会话并请求目录同步 | 保留当前合法焦点 |
| 操作栏已可见，Finder 选区变化 | 更新选区摘要与建议 | 不创建会话；已有 Run 上下文不变 | 不改变焦点 |
| Finder 开始移动 | `temporarilyHidden`，收起依附面板 | 保留当前与后台会话，不执行 `hideBehavior` | 不主动抢回 |
| Finder 停止移动且显示条件仍满足 | 恢复原会话的操作栏 | 不创建新会话；按最新目录同步 | 恢复前不主动聚焦 |
| Finder 失焦到其他应用 | 临时隐藏依附操作栏 | 保留会话；不结束任务 | 焦点交给目标应用 |
| 用户进入 Fleqi 自己的操作栏/面板 | 仍属于同一交互组，不按 Finder 失焦隐藏 | 保留会话 | 按控件操作移动 |
| 从系统暂隐返回有效 Finder | 恢复原显示周期与会话 | 不新建；同步最新目录 | 自动恢复不抢焦点 |
| 用户主动隐藏，`keepAll` | 隐藏并设置 `autoShowSuppressed=true` | 已运行 AI/PTY 全部后台保留；撤销尚未投递的自动 `cd` 和命令，命令留作草稿 | 归还原 Finder/外部应用 |
| 用户主动隐藏，`endAll` | 隐藏并暂停自动显示 | 结束全部会话、关联 AI 任务及 PTY | 不因结束完成而重新出现 |
| 主动隐藏后仅移动/激活另一 Finder | 保持隐藏 | 不把旧后台会话自动带到新 Finder | 不抢焦点 |
| 用户显式再次显示 | 清除自动暂停，显示新会话 | `keepAll` 下旧后台仍在，默认不自动选回 | 主动显示聚焦输入 |
| 用户实际更改 `activation` | 清除自动暂停，按新模式判断 | 仍可见时复用当前；需要开始新显示周期时新建 | 改成自动后自动出现不抢焦点 |
| 无有效 Finder 目录，自动模式 | 不自动创建无目录会话 | 等待有效上下文 | 不抢焦点 |
| 无有效目录时用户主动显示/打开终端 | 打开文件夹选择；不猜用户目录或磁盘根目录 | 选择有效目录后创建会话 | 聚焦目录选择 |
| 权限被撤销或目录不可访问 | 暂隐依附条；控制台显示原因与选择文件夹入口 | 不把事件解释为主动结束；已有任务按实际执行结果更新 | 不循环弹权限窗 |
| 应用重启 | 按设置重新判断显示条件 | 历史可读，PTY/进程不复活；新显示创建新会话 | 遵守手动/自动规则 |

手动显示事件与“临时隐藏后的恢复”必须使用不同事件名称。临时隐藏期间如果用户又主动隐藏、禁用操作栏或更改模式，旧恢复事件失效，不能将操作栏弹回。取消自动暂停只由显式再次显示或实际更改唤起模式触发；修改其他设置、任务完成、Finder 选区变化都不解除暂停。

### 3.3 目录显示和自动 `cd` 场景矩阵

操作栏同时维护两种可读信息：`FinderContext` 是当前展示的工作上下文；`currentDirectory` 是 PTY 实际工作目录。正常同步后只需显示一条路径；不一致时显式展示两者。

| 事件与 PTY 状态 | 宿主动作 | UI 必须显示 | 输入规则 |
|---|---|---|---|
| 新会话，有有效 Finder 目录，但尚无 PTY | 记录当前目标目录；AI 会话可先工作 | “工作目录：… · 终端未启动” | AI 使用展示的快照；`!`/打开终端时按需启动 |
| 首次提交 `!` 或打开终端 | 在当前有效目标目录创建 PTY | 创建中；实际回报后显示真实目录 | 创建/目录确认完成后允许投递命令 |
| 可见会话，shell 空闲提示符且编辑行为空 | 同步到最新有效 Finder 目录 | 短暂“正在切换目录…”；成功后更新真实目录 | 同步完成后提交 |
| 前台命令或交互程序运行 | 更新 `pendingDirectory`，不向程序输入 `cd` | “终端：A · 将切换到 B（程序结束后）” | 新 `!` 提交等待；终端面板按键仍直通当前程序 |
| shell 已到提示符，但编辑行非空 | 等待用户处理该行 | “终端：A · 将切换到 B（当前输入完成后）” | 不清空用户行、不注入 `cd`；新 `!` 等待 |
| 等待期间 Finder 又从 B 切到 C | 将待切换目标合并为最新有效 C；撤销对 B 提交命令的自动投递 | “将切换到 C”及“目录已变化，请重新提交” | 原命令回到可编辑草稿，不自动改在 C 执行 |
| 安全提示符出现且待提交绑定的目标没有变化 | 校验目标并切换 | 等待→切换中→已同步 | 成功后仅发送一次仍有效的待提交命令 |
| 无法可靠确认安全提示符/空编辑行 | 保持待同步，不猜测 | “等待终端可切换目录”及打开终端入口 | 不自动写入终端 |
| `cd` 失败 | 保持真实旧目录和错误 | “无法切换到 B”，可重试或选择目录 | 待提交命令保留，禁止误在 A 执行 |
| 后台会话遇到 Finder 变化 | 不修改该会话目录 | 列表仍显示该会话真实目录 | 不唤醒、不注入命令 |
| 当前会话切到后台或用户主动隐藏 `keepAll` | 撤销尚未投递的自动 `cd` 和 `queuedLine`；已运行 AI/PTY 继续 | 待发送命令回草稿，说明“会话已切到后台，命令尚未执行” | 后台到达提示符也不自动 `cd` 或执行旧草稿 |
| 用户切回后台会话 | 保留其终端/历史，随后按当前 Finder 同步 | 真实目录与待切换目录 | 同样遵守忙碌/编辑行等待规则 |
| 用户在终端面板自行 `cd` | 显示宿主报告的真实目录 | 真实目录可能与 Finder 不同 | 不伪造同步成功；下一次有效 Finder 目录变更/会话切回再触发同步 |
| 在目录待同步时提交 AI 请求 | 使用已展示的最新有效 `FinderContext` 快照创建 Run | 任务详情明确该 Run 的目录与选区 | 不等待 PTY、不向 PTY 注入命令 |
| 已有 AI Run 运行期间切目录 | Run 保留提交时快照 | 详情显示原目录；主条显示最新上下文 | 不改变已批准 Run 的目标 |

`pendingDirectory`、安全提示符和真实目录由宿主提供；前端不能通过匹配屏幕上的 `$`、`%` 或目录文字判断 shell 空闲。待发送手动命令以 `queuedLine` 保存，携带 `requestId`、会话 ID、提交时目标目录及上下文版本。目标目录未变化且同步确认后自动发送一次；目标变化立即撤销旧自动投递并恢复草稿，不把用户对 B 提交的命令暗中改在 C 执行。若用户已经编辑另一份草稿，不覆盖它，而显示可恢复的原命令。切换、结束、删除会话后，旧回执不得将命令发送到其他会话。

PTY 按需创建：纯 AI 会话没有 `terminalId` 时直接显示其工作上下文和“终端未启动”；首次打开终端或提交 `!` 时在当前有效目标目录创建 PTY。UI 不为每个纯 AI 会话制造假终端提示符，也不把尚未启动的 PTY 显示为已同步。

自动目录控制只服务当前可见会话。切换到其他会话或主动隐藏后，取消尚未投递的自动目录控制与 `queuedLine`；保留手动命令为草稿，已运行进程继续。已经投递的控制回执只如实更新原会话事实，不因它启动下一次后台同步或命令。Finder 移动/失焦造成的暂隐只暂停自动投递，恢复原显示周期后重新校验当前会话和目标；若目标已变化，仍按目标变化规则撤回命令，不执行用户隐藏策略。

## 4. 主操作栏 `UI-COMPOSER`

### 4.1 两行布局

以下为新界面结构；尺寸均是设计默认值，不是从录屏像素反推的逻辑尺寸。

```text
┌─────────────────────────────────────────────────────────────────────────────────┐
│ 隐藏  任务状态  [AI / 终端] 输入内容…       提交  建议  更多操作  终端  会话 ▾       │
│ 当前上下文：目录 · 已选 N 项                 AI 执行策略       模型名 ▾              │
└─────────────────────────────────────────────────────────────────────────────────┘
```

在终端模式或目录不同步时，第二行优先显示真实终端目录和“将切换到…”；Finder 上下文可从目录摘要展开查看。模型入口在手动终端模式下由“手动终端 · 直接执行”标签替代，避免用户误以为按模型策略批准手动命令。

| 参数 | 设计默认值 | 行为 |
|---|---|---|
| 高度 | 72 逻辑像素；主行 32，次行 20，剩余为边距 | 紧凑状态固定两行，不把日志塞进主条 |
| 宽度 | 与 Finder 窗口等宽（最小 560；用户明确要求等宽，屏幕工作区为硬限制，不设 1120 上限） | 小窗口/短屏以屏幕安全区为硬限制，不越界 |
| 圆角 | 16 | 与控制台表面区分，但使用同一颜色体系 |
| 内边距/间隙 | 水平 12，控件间 6–8 | 输入区弹性伸缩，操作按钮不相互覆盖 |
| 图标 | 主行 16，次行 13 | 命中区至少 24×24，主要操作首选 28×28 |
| 输入字体 | 14，行高 20 | 中英文输入不因模式变化跳尺寸 |
| 次行字体 | 12，行高 16 | 路径中间省略，完整值可复制/查看 |
| 与 Finder 间隙 | 外侧下方 4 | 屏幕底部无空间时改为内侧贴底；位置变化不使用拖尾补间 |
| 安全区 | 所在显示器可用工作区四边至少 8 | 避开菜单栏、Dock 等不可用区域；具体坐标由宿主计算 |
| 建议预算 | 默认最多 3 条 | 空间不足先收建议，再收次要文字，不隐藏模式/提交/会话入口 |

若宽度低于 560，将建议收进“更多操作”，缩短模型/策略标签；低于 420 时只保留隐藏、任务、模式、输入、提交、会话，终端和其他入口进入明确的更多菜单。窗口很窄时允许条宽超过 Finder，但必须在当前显示器工作区内。主条不依赖水平滚动访问动作。

原生承载（2026-09-20）：72px 是紧凑主条高度，不是浮层展开时的整个 WebView 高度。会话、终端、结果与规划反馈在同一窗口内向上展开；宿主接受额外 0–480px 的布局申请，并按所在显示器工作区限高，主条保持底部 72px。关闭面板后恢复紧凑高度；布局变化不能触发新会话或主动隐藏行为。

### 4.2 AI 输入

- 占位：“输入指令或问题”；无模型时保持可编辑，提交前显示“配置模型 API”入口。可本地完成的能力不因未配置模型而全部禁用。
- 展示当前目录、选区数量和类型；选择变化刷新建议，不清空草稿。
- Enter 提交；Shift+Enter 输入换行。长内容在输入编辑器内部扩展/滚动，扩展区作为锚定编辑层，紧凑条不无限增高。
- 提交时形成新的 Run，记录当前展示的有效上下文快照；输入及时恢复，允许后续请求。需求默认全局 AI 并发上限为 4，达到上限显示排队状态而不是吞掉输入。显式选中项超过默认 1000 项时要求缩小范围，不静默截取前 1000 项执行。
- 提交动画不能是启动任务的唯一触发点；关闭面板、减少动态或动画中断不会丢失已提交请求。重复点击在同一提交 ID 下只创建一个 Run。
- 任务策略为“只读自动，改动确认”时持续显示简短标签；YOLO 使用明确文字“YOLO · AI 自动执行”。切换只影响之后按架构规则评估的动作，已经等待批准的任务不能被 UI 无声批准。
- “回应/细化”携带来源 Run ID，输入上方出现可关闭的引用条，显示原请求摘要和该 Run 原上下文；新 Run 的工作上下文按当前已展示快照确定，差异在提交前可见。

### 4.3 `!` 手动终端输入

- 首个非空字符是半角 `!` 时识别为手动终端；定位该标记后只删除这个字符，其他空白和文本保持原意。全角 `！` 和普通句子中间的 `!` 不切换模式。
- 从 `!` 到输入末尾全部使用终端绿色；同时显示“终端”文字/图标。不能只靠绿色区分模式。
- 删除起始 `!` 后恢复 AI 模式，保留剩余草稿；不触发提交。首版不给 `!!` 增加另一套特殊语法，第一个 `!` 是模式标记，其余内容按终端输入处理。
- 提交到指定会话 PTY 的内容去掉第一个模式标记。末尾发送一次终端回车；输入为空或只有 `!` 时不发送空命令，展示“输入终端命令”。
- 手动终端不调用模型，不进入 AI 风险确认流程。标签为“手动终端 · 直接执行”，避免与 AI 策略混淆。
- PTY 忙、编辑行占用或目录未同步时，保留输入；按真实原因分别显示“等待终端空闲”“等待当前输入完成”“等待切换目录后执行”，并提供“取消等待”“打开终端”。每个会话首版仅保留一个等待发送的操作栏命令，等待期间新的草稿可以编辑，但不能静默替换已经提交的命令。
- 等待状态中取消只取消尚未发送的命令，不中断前台程序。等待期间目标目录变化时自动撤销这次投递，保留为草稿并提示“目录已变化，请重新提交”；不把它发送到新目录。会话切后台或主动隐藏 `keepAll` 时也撤销尚未投递动作、保留草稿；结束/删除该会话取消其待发送命令。
- 用户要向正在运行的程序输入时使用 `UI-TERMINAL`；操作栏的 `!` 不把一条新 shell 命令写进交互程序。

### 4.4 主条状态文案

| 状态 | 文案和动作 | 输入是否保留 |
|---|---|---|
| 正常、无选择 | “当前文件夹：…”；按目录给通用建议 | 是 |
| 无有效目录 | “请选择工作文件夹” → 选择文件夹 | 是 |
| 读取上下文中 | “正在读取 Finder…”；暂停需要该上下文的新提交 | 是 |
| 上下文不可访问 | 显示原因，选择文件夹/检查权限 | 是 |
| AI 正在执行 | 任务图标带数量；输入可继续 | 是 |
| AI 待批准 | 徽标“待确认 N”，点击定位 Run | 是 |
| 手动命令目录等待 | “终端：A · 将切换到 B”，取消等待/打开终端 | 是 |
| 目录同步失败 | “无法切换目录”，重试/选择目录 | 是 |
| 创建会话失败 | 说明失败与重试，不显示假提示符 | 是 |
| 会话已结束 | 只读提示，按钮“创建新会话” | 是，归属于原会话历史而不自动执行 |

## 5. 会话选择器 `UI-SESSION-SELECTOR`

### 5.1 外观与内容

从操作栏右侧会话控件展开带尖角的气泡面板。默认宽 400、最大高 480 逻辑像素，按工作区限高；箭头始终指向触发控件，不要求面板中心与触发控件中心重合。

顶部显示“会话”、搜索、创建新会话；下方以“置顶”“活跃”“历史”分组。置顶组可以包含活跃和历史会话，每条仍显示自己的状态。组内设计默认按最近活动倒序；置顶时间不改变历史内容顺序。键盘选择、搜索结果和后续本地化不改变稳定会话 ID。

每条内容：

- 名称：取用户首条输入的短摘要；尚无输入时显示目录名称和创建时间。
- 次行：真实终端目录或已结束会话最后目录；运行任务数/等待批准状态。
- 右侧：**删除按钮在左，图钉按钮在右**。所有行在悬停和键盘焦点时都能访问这两个按钮；窄面板也不能颠倒顺序。
- 单会话更多菜单：打开终端、查看任务、结束当前会话；历史条目提供查看历史、继续为新会话。

图钉只修改列表置顶元数据，不调用原生窗口置顶。删除删除的是该会话及本地历史；文案明确“不会删除此会话操作过的文件”。

### 5.2 会话操作契约

| 操作 | 结果 | 列表与终端表现 |
|---|---|---|
| 选择活跃会话 | 切换到它，保留终端内容，随后按当前 Finder 请求目录同步 | 选中态立即明确；目录等待显示真实状态 |
| 选择历史会话 | 打开只读历史 | 不重建 PTY、不自动执行最后命令 |
| 历史“继续” | 创建新的会话，关联来源历史 | 新 ID，以当前有效目录作为工作上下文；终端按需新建，旧历史仍只读 |
| “新建会话” | 创建新会话并选中 | 旧会话继续后台运行，除非用户明确结束；达到默认 16 个活跃会话时说明上限并提供选择/结束会话入口，不偷偷回收旧会话 |
| 结束当前 | 结束该会话的 PTY、AI 任务与待发送输入，保留历史 | 活跃→结束中→历史；不删除记录 |
| 删除当前/其他会话 | 先终止该会话活动，再删除本地记录与索引 | 显示 `UI-DATA-CONFIRM`；失败保留可恢复条目，不假装成功 |
| 置顶/取消置顶 | 移动整条会话至相应组 | 保留会话内容、目录和活动状态 |
| 应用重启 | 所有持久记录以历史呈现 | 不显示“进程仍运行”；中断任务标记已中断 |

结束或删除当前会话后，不静默切到另一个后台会话；面板显示“当前会话已结束/删除”和新建/选择入口。操作栏热键再次显示的正常默认仍是新建。

### 5.3 主动隐藏与结束全部

主条左侧隐藏按钮、已注册的切换快捷键及应用菜单“隐藏操作栏”统一发出 `userHide`。按钮 tooltip 随持久设置显示“隐藏，保留全部会话”或“隐藏，结束全部会话”。

设置中从启用切为禁用也是用户明确关闭操作栏，按同一 `hideBehavior` 处理一次；开关说明展示该影响。之后系统重复报告已禁用状态不再次终止/清理会话。

`keepAll` 下，已运行 AI/PTY 在隐藏期间可以继续并完成，但不弹回操作栏、不在其他 Finder 上自动显示后台会话。尚未投递的自动 `cd` 和 `queuedLine` 撤销，命令保留为草稿；不能等后台程序退出后偷偷改目录或发送命令。结果保存在列表，之后由用户选择查看。

`endAll` 下，UI 发出结束全部请求，停止新提交并清理所有待发送输入，宿主负责取消关联 AI 工作和 PTY。若某会话终止失败，在控制台/菜单状态保留失败提示和处理入口；不得以隐藏成功冒充所有进程已结束。此设置不是每次隐藏重复询问的确认框。

## 6. 共享任务浮层

### 6.1 容器与导航

`UI-RUN-LIST`、`UI-RUN-DETAIL` 的预览、安装、执行输出和完成详情共用一个锚定面板。默认宽 480、最大高 560 逻辑像素；内容区滚动，返回/主要动作始终可达。空间不足时先翻转，再限高；两侧都不足时使用工作区内的扩展面板，不允许批准按钮移出屏幕。

入口：任务指示器、Run 行、结果气泡“详情”、控制台任务入口。进入详情保存列表过滤、滚动位置和触发行；返回恢复这些位置。面板关闭只改变显示，不取消、批准、结束或删除任务。

### 6.2 `UI-RUN-LIST`

顶部标题“本会话任务”，可切“全部/进行中/待确认/已完成”；上下文来自被选中的会话，不以当前 Finder 目录过滤掉该会话旧任务。行内显示状态图标、请求摘要、结果/进度、时间、收藏与详情入口。

领域 Run 状态统一为 `planning / awaitingInput / awaitingApproval / installing / queued / running / succeeded / partiallySucceeded / failed / cancelled / interrupted`。生成与预测是 `planning` 的展示阶段；缺参数为 `awaitingInput`。摘要独立使用 `notRequested / pending / ready / failed`，不能为了显示“解读中”把已成功 Run 改回运行态。收藏也是独立操作。

| 行状态 | 显示与可用动作 |
|---|---|
| 排队/生成/预测 | 阶段文字和不确定进度；查看、取消 |
| 等待批准 | “等待确认”，查看变更；主列表不提供没有预览的盲目批准 |
| 安装/执行 | 当前阶段、确定或不确定进度；查看、取消 |
| 解读 | “执行已完成，正在整理结果”；原始输出仍可访问 |
| 成功 | 一句话结果；详情、收藏、再次运行 |
| 部分失败 | 成功/失败数量并列；查看逐项结果，不显示全成功勾 |
| 失败 | 简短原因；详情、重试（作为新 Run） |
| 已取消/已中断 | 已取消阶段/重启中断；详情、重新发起 |

空状态：“这个会话还没有任务”，动作聚焦操作栏输入。清空已完成仅清理终态任务记录，不取消活动任务、不删除收藏或用户文件；使用明确范围的 `UI-DATA-CONFIRM`，对应视频 96.50s。列表外跳入某 Run 后滚动定位并短暂高亮，减少动态时采用静态选中框。

### 6.3 `UI-RUN-DETAIL` 固定结构

1. 顶部：返回任务列表、请求短标题、收藏按钮。
2. 上下文：Run 创建时目录、选区摘要、来源为 AI/能力、模型与策略。与当前 Finder 不同也保留原值。
3. 主体：按阶段显示生成、依赖、命令/操作计划、影响预览、输出与结果。
4. 底部：与当前阶段匹配的动作；最多一个主要提交动作，取消/返回使用次级样式。

命令与路径可复制，命令代码区使用等宽字体。长路径中间省略但可展开；影响列表使用“动作 + 来源 + 目标 + 说明”，同名文件不能仅凭截断文件名区分。

通用桌面命令不能全部强塞进“文件变化”表。根据计划类型补充以下字段，参数来自当前请求/能力表单，不从来源示例填充：

| 操作类型 | 执行前与结果中必须可核查的信息 |
|---|---|
| 文件/媒体/文档 | 输入与目标、格式、排序、页/时间范围、是否处理原件、实际生成文件和逐项结果 |
| 系统/硬件 | 目标设备/卷/应用/设置、作用范围、持续时间、系统返回的实际状态；未知字段明确标“系统未提供” |
| Git | 仓库、暂存范围、提交消息、远端和分支；暂存/提交/推送分别记录，推送失败不抹掉已经提交事实 |
| 网络/下载/天气 | 目的主机或 URL、协议/超时、保存位置或地点/单位、来源和观测/预报时间；歧义地点要求补参数 |
| 消息/打印 | 收件对象/服务或打印机、内容/附件、份数/页范围；受理和真正送达/完成的证据层次明确区分 |
| 计算/单位换算 | 用户数值、原单位/目标单位、精度和取整口径，不使用来源 ID 中的示例数字 |
| 检索/选择文件 | 实际检索范围、未读取/未索引部分、跨目录结果分组、定位和选择入口；部分可读结果不是完整空结果 |

动作列表由宿主返回的实际可执行操作控制。取消展示已经产生的副作用，不承诺通用回滚；已经发出的消息、打印/休眠请求等不可撤回动作，要显示已发送事实和取消范围，不能留下承诺能撤销的假按钮。

### 6.4 AI 执行策略与批准状态

| 策略 | 只读 AI 动作 | 会改动的 AI 动作 | 手动终端 |
|---|---|---|---|
| `readOnlyAutoConfirmChanges`（默认） | 自动执行，保留可查看计划/记录 | 先展示当前版本影响预览，再批准；未知影响按需批准处理 | 不进入本流程 |
| `yolo` | 自动执行 | 不等待用户确认；仍展示实际阶段、结果与失败 | 不进入本流程 |

YOLO 取消的是 AI 确认步骤，不取消能力校验、工具完整性检查、系统权限条件或错误处理。UI 不允许把校验失败展示为“已自动批准”。策略切换按宿主契约生效；当前详情展示任务实际采用的策略。

等待批准页包含：计划摘要、可展开命令、影响分类和逐项源/目标、未能确定的信息、缺失条件。底部为“取消任务”“编辑”“确认执行”。编辑后旧预览失效，进入重新分析，批准按钮在新预览有效前不可用；确认绑定 `runId`、`planRevision` 与上下文快照。

使用 `yolo` 时不先呈现需要用户点击的 Confirm 再自动模拟点击。应直接进入相应执行状态，并留下可查看的计划记录。

### 6.5 工具安装

缺工具时，详情显示工具名、用途、来源、许可/版本信息、安装范围、下载/校验状态以及“安装后才能完成预测”的明确提示；不能把尚未计算出的影响写成“无改动”。

- 默认策略下，由 AI 请求的安装是会改动的动作，呈现安装批准，再下载/校验/安装；安装完成后重新计算目标任务影响，需要批准的文件改动仍须展示新预览。
- YOLO 下按同一依赖流程自动推进，不插入用户确认；校验或安装失败停在可操作错误态。
- 用户在工具页主动按“安装”发起的管理动作由该页给出具体范围和状态，不冒充 AI 请求，也不重复弹出相同批准。
- 安装中显示已下载量/真实进度、取消入口。取消或失败后保留重试和详情，不无声继续目标任务。

该结构采用视频 118.00s 的信息关系，不照搬其工具下载站、品牌和命令。

### 6.6 输出、摘要与再次运行

执行时输出区增量更新；stdout/stderr 的视觉标记由实际数据决定，不靠内容猜测。用户在底部时自动跟随新输出；上滚后暂停自动滚底，显示“有新输出 · 回到底部”。输出量超过显示缓冲时给出截断标识和分页日志入口。需求默认每 Run 日志最多 50 MiB、每 Session 日志最多 100 MiB；达到持久上限后必须显示“记录已截断”。被截断记录的复制动作改为“复制已保留输出”，不能声称复制了完整原始输出。

结束后区分“执行结果”和“AI 摘要”。摘要失败不改变执行成功/失败，回退到退出状态、计数和可读输出。原始输出仍在本面板；完整复制与复制摘要是两个有名称的动作，不共用含糊“复制”。

“再次运行”创建新 Run，保留来源关联，展示当前新上下文，重新进行必要的依赖/影响处理；不会重新激活旧 Run 或绕过新预览。批量结果显示逐项状态与目标位置；部分失败时重试范围必须明确，不默认重复全部已成功项。

## 7. 结果气泡 `UI-RESULT-BUBBLE`

气泡锚定到任务状态入口；默认最大宽 420 逻辑像素。第一行是图标、简短结论、关闭和详情；第二行提供“复制结果”“回应”。文字最多显示两行，完整内容进入详情。键盘焦点/鼠标停留期间暂停自动消失，读屏用户聚焦后不因定时器丢失内容。

设计默认显示 4.8 秒，可配置 1–30 秒，步进 0.1；`null` 表示常驻并显示关闭按钮。关闭仅取消该气泡展示，不删除 Run。定时消失后结果始终保存在任务列表。

用户已经打开该 Run 详情时不再弹同一气泡；多个任务相继完成时使用有上限的展示队列，任务指示器保留未读状态，不在屏幕堆叠气泡。主条因用户隐藏或系统暂隐不可见时，仅登记未读结果，不能为结果强行唤起主条。

失败用图标与文字说明；不依赖红色。应用级模态出现时可保留气泡的被动视觉，但暂停计时并设为不可交互，模态结束后恢复。

## 8. 交互终端 `UI-TERMINAL`

### 8.1 面板结构与连接

终端使用 xterm.js 类终端显示区连接 Rust PTY 服务；具体库版本和协议以[架构](architecture.md)为准。该区域是可交互终端，不是日志文本框。AI 一次性任务日志仍在任务详情，不能把它们混写进正在交互的 PTY。

标题栏显示会话、真实目录、运行状态、待切换目录、展开到控制台与收起面板。没有 `terminalId` 时显示“终端未启动”，用户打开终端才在当前目标目录初始化；创建成功前不显示假提示符或“目录已确认”。收起终端面板不隐藏整个操作栏、不执行 `hideBehavior`、不结束会话。结束当前放单会话菜单。

默认锚定终端面板宽 800、高 360 逻辑像素，可在工作区允许范围内调整；完整控制台终端复用同一会话内容，不额外新建 shell。由当前可见终端视图拥有键盘输入和尺寸控制权；切换视图时转移所有权，避免两个面板同时发送按键或互相覆盖 PTY 尺寸。

macOS 的“收起终端”位于标题栏左侧，使用红色圆点，悬停显示 X；其他平台保留右侧关闭按钮。终端内容采用独立深色配色（背景 `#18191b`、正文 `#f3f4f6`），不继承浅色管理界面的正文颜色；明确设置光标、选区和 ANSI 调色板，最小文字对比度设为 7。面板圆角 16px、内容四周留白 12px，输出和滚动区均在边界内裁切。

终端、任务、会话与规划反馈先完成离场，再收回原生窗口空间；离场期间立即退出焦点序列，快速重开接续当前过渡。macOS 在一次 AppKit frame 更新中同时改变窗口大小和位置，保持输入条底边；原生玻璃仅绘制输入条底板，浮层自己绘制并裁切内容表面，不额外叠加与其尺寸、过渡不同步的玻璃底板。

### 8.2 尺寸、输出与滚动

- 终端布局变化后按实际内容区计算列/行，发送带会话 ID 的 resize；折叠/隐藏不发送无意义的 0×0 尺寸。
- 字体、缩放倍率和窗口尺寸改变后重新计算；尺寸变化不清空终端输出或新建会话。
- 普通滚动缓冲按需求默认保留 10,000 行；更多历史从分页日志查看，并受每 Session 100 MiB 持久上限约束。显示缓冲与持久记录的截断分别标记。
- 交互程序的屏幕控制、光标与备用屏幕由终端处理，不把其控制序列展示成普通正文。
- 用户滚离底部时不强行滚回；程序自行控制屏幕和终端滚动缓冲是两个概念，不能对全屏交互程序套用任务日志的自动滚底逻辑。
- 历史会话终端只读，显示“会话已结束”，无可输入光标；“继续”创建新会话。

### 8.3 输入与中断

终端焦点范围内，Enter、Tab、方向键、Esc、Ctrl+C、Ctrl+D 等按终端协议交给当前程序。macOS 使用 Command+C 复制选区、Command+V 粘贴；Ctrl+C 保持终端中断语义。没有选区时，复制快捷键不改为复制最近 AI 结果。

中文预编辑在终端输入代理中正常工作，组合完成后只发送一次实际文本；不得把 composition 中间值反复写入 PTY。粘贴使用终端可用的粘贴协议，保留多行及控制边界；不通过 AI 分析或更改用户文本。

在 shell 目录待同步时，终端面板仍能输入，用于退出程序、完成/清空当前编辑行等；这是用户直接终端输入。只有从操作栏发起的新 `!` shell 命令等待安全目录同步。UI 不把“目录待同步”实现成冻结整个终端。

显示“中断当前程序”动作时，它对应终端中断；“结束会话”终止会话并保留历史，两者不能复用按钮文案或回调。任务详情中的“取消 AI 任务”只作用于指定 Run。

## 9. 控制台各页面

### 9.1 工作区 `UI-WORKSPACE`

复刻窗口、侧栏、顶部面包屑和两列卡片。顶部概况只显示真实数据：活跃会话、进行中/待批准任务、当前模型配置与工具可用状态。首次使用可出现“配置模型 API”“设置唤起方式”“检查 Finder 权限”三个紧凑配置入口；不显示购买、试用或账号营销。

六张卡片覆盖文件与文件夹、ZIP、图片、音频与视频、PDF、文本与文档。点击进入能力页对应文件视图；卡片文字按真实能力目录生成，不手写与目录不一致的支持格式。下方按钮进入文件处理设置。

没有模型时说明 AI 尚未配置，同时保留手动终端和已具备条件的本地能力；没有会话时显示“显示操作栏/创建会话”的有效入口，不自动替用户唤起。

### 9.2 能力与建议 `UI-CAPABILITY-LIBRARY`

完整目录采用十类：视频与音频、图片、文本、PDF、ZIP、文件操作、计算、系统与工具、开发者、其他。六类 30 项文件能力卡片是同一目录的视图，不是第二份互相漂移的数据。105 项操作意图与 30 项基础能力的稳定 ID、参数、平台及依赖以[能力目录](capabilities.md)为准；共享实现不意味着可以省略各自验收或搜索入口。

页面包含搜索、分类、当前上下文筛选、收藏过滤；每条显示标题、简短说明、输入类型/数量约束、需要的工具、可用状态和收藏。不可用条目仍可浏览，说明“需要选择文件”“缺少工具”等具体原因，不把首版能力显示为下一版占位。

点击能力后：无参数且符合条件的条目显示本次目标；有参数的显示有标签的参数表单、默认值、单位、校验和目标预览。应用用户输入前不把示例值当真实路径。后续执行按该入口所属的 AI/显式管理动作及架构规定处理；能力建议不能伪装成 `!` 绕过 AI 策略。

主条建议取当前上下文相关条目，默认最多三条，不打开自动大弹窗；“更多操作”打开锚定的同源能力浏览视图。中文/英文搜索映射到稳定能力 ID，不能因改文案丢失收藏。

### 9.3 规则 `UI-RULES`

左侧规则列表与搜索，右侧编辑区；空态说明规则如何影响 AI 请求，并提供“新建规则”。字段包括名称、启用开关、触发短语列表、范围、文件夹选择和规则正文。范围支持全局、指定文件夹、短语命中、文件夹且短语命中；正文提供长度提示而不偷偷截断。

保存前校验空名称、无效范围、重复短语与不可访问目录；错误关联对应字段。关闭未保存编辑时提供保存/放弃/继续编辑。保存失败保留草稿。规则显示命中范围预览，不把规则文本视作可自动执行的终端命令，也不能用规则关闭 AI 策略。Run 详情列出实际生效规则，旧 Run 保留当时规则快照；修改只影响新任务。

### 9.4 收藏 `UI-FAVORITES`

列表显示名称、来源能力/请求、适用输入、最近使用；可搜索、编辑标签、取消收藏、使用、导入/导出。收藏星标在能力、Run 详情和收藏页同步，以稳定 ID 表达，不能只靠标题去重。

使用 AI 收藏创建新 Run，重新展示当前上下文和参数；手动命令收藏保持手动来源，进入 `!`/终端路径，遵守同一目录同步规则，不改为 AI 请求。收藏不保存“永久自动批准”效果；来源由宿主验证，模型不能把 AI 收藏伪称手动命令。导入 JSON 提供条目数量、可识别/无效项、重复处理方式和应用前预览；导入错误保留原收藏。导出位置由用户选择，不包含模型密钥。

### 9.5 模型 `UI-MODELS`

页面标题“模型与 API”；包含用户配置的服务列表和编辑器：显示名称、接口类型、端点地址、密钥输入/替换、可用模型、默认生成模型、结果摘要模型、连接检查。允许支持的自定义兼容端点；本地服务是否需要密钥按端点配置决定，不强制虚构密钥。

密钥默认遮罩，保存后展示“已保存凭据”而非回填明文；连接检查分别呈现连接失败、认证失败、模型不可用和成功。检查动作期间按钮显示进度，可取消；失败不清空用户端点与模型选择。

主条模型选择面板只显示已配置可用模型和“管理模型”入口。没有可用模型时显示配置动作。模型选择失败恢复实际生效值。首版不包含账号登录、自营代理余额、订阅和语音会话配置。

### 9.6 工具 `UI-TOOLS`

工具目录按可用/未安装/需处理筛选。每条显示名称、版本、作用、检测来源、安装位置与依赖它的能力；详情列来源、许可信息、包大小（可得时）、安装/卸载动作。

安装状态依次展示检测、下载、校验、安装、可用；无法确定进度时用不确定指示器，不制造百分比。失败说明可重试步骤，保留诊断入口。卸载展示对能力的影响；使用中的工具不允许静默破坏正在运行的任务，具体服务拒绝/等待策略以架构为准。

刷新重新检测实际工具状态，不删除用户已配置路径。系统已有工具与 Fleqi 管理工具清楚标示；不能给不可管理的系统工具显示会失败的假卸载按钮。

### 9.7 权限 `UI-PERMISSIONS`

展示 Finder 上下文、窗口定位和选区读取所需权限及自检结果。每项有当前状态、用途、检查时间、打开对应系统设置入口和重新检查；状态未知先显示“正在检查”，不能先显示绿色成功再改成失败。

授权帮助给简短步骤和返回检测按钮；权限撤销时说明哪项能力受影响，并提供手动选择目录继续工作的入口。无需 Finder 权限的本地管理和历史查看保持可用。不能把“不支持”“未授权”“暂时失败”都写成“请授权”。

首次配置可以依次引导选择唤起方式、配置需要的 Finder 权限、选择工作目录和模型；每步允许返回，模型未配置不阻止手动终端。没有付款、激活或强制账号步骤。

### 9.8 关于 `UI-ABOUT`

显示 Fleqi 名称、真实版本/构建、AGPL-3.0-only 许可、项目来源链接、第三方许可、隐私说明、帮助与反馈、检查更新。更新状态覆盖检查中、已最新、发现版本、下载、验证、可安装、失败。只有用户显式发起反馈/导出诊断才操作对应数据；诊断界面给出内容范围，不将凭据或完整文件内容默认附带。

Windows/Linux 后续版本复用这些信息架构和稳定 ID；平台不可用信息使用能力状态表达，不把 macOS 权限名称或窗口控制硬编码到公共界面。

## 10. 七类设置 `UI-SETTINGS`

### 10.1 外壳与保存

保留七类分栏外壳：**通用、外观、模型与 API、权限与自检、文件与工具、任务与诊断、关于与更新**。终端设置放在任务与诊断中；模型/权限/关于复用上述页面，不复制第二份状态。规则、收藏、工具在控制台有直接入口，相关设置页可以链接过去。

开关和选项更改后显示保存中，宿主返回成功快照后才标“已保存”；失败显示行内重试并恢复实际生效值，用户草稿可保留。敏感配置、路径和快捷键使用明确保存/验证。多窗口修改冲突展示最新值与未保存编辑，不能悄悄覆盖。

### 10.3 快捷键录入

录入流程：未设置/已有值 → 录入中 → 候选 → 检查/注册 → 成功或冲突。支持用户选择单键及组合键，不沿用旧录入器“必须含修饰键”的限制。物理键与显示名称由平台适配，保存稳定键标识与修饰符，展示平台用户熟悉的名称。

录入中显示“按下要使用的按键；Esc 取消”，提供鼠标可点击取消。Esc 的单键录制通过“录入 Esc”明确入口完成，避免与默认取消冲突；纯修饰键/系统保留键如不被原生注册器支持，应报告真实原因，不假装“任意键都成功”。单键注册成功后，字段说明其全局切换用途；不得一边把该键作为全局切换键，一边宣称它仍会无条件作为普通字符发送到终端。

候选未注册成功前旧热键保持有效；录入期间暂停会干扰录制的 Fleqi 自身快捷键，结束/失焦/取消后恢复。注册失败保留候选和原有效值。按住热键重复触发只执行一次显示/隐藏动作；录入组合键不把同一次按下又当作立即隐藏。

## 11. 键盘、焦点与无障碍

### 11.1 焦点所有权

自动显示/系统恢复只呈现操作栏，不把 Finder 的键盘输入转给 Fleqi。点击输入、使用有效热键手动显示、用户显式返回输入才聚焦输入区。打开会话/模型菜单时焦点进入菜单；关闭后回到触发控件。任务面板主动打开时聚焦其标题/首个合适控件，自动结果播报不抢焦点。

记录打开者元素和所属窗口；返回时如果原对象已销毁，使用同一会话中仍存在的合理入口，不聚焦其他会话。原生 Finder 与 Fleqi 自身交互组的焦点切换由宿主识别，不能因为点击 Fleqi 面板而立即触发失焦隐藏。

### 11.2 键盘作用域表

| 作用域 | 按键 | 行为 |
|---|---|---|
| AI 输入，非预编辑 | Enter / Shift+Enter | 提交 / 换行 |
| AI 输入，非预编辑且光标在历史浏览边界 | ↑ / ↓ | 浏览本会话输入历史；多行编辑时优先移动光标 |
| `!` 操作栏输入，非预编辑 | Enter | 提交到本会话终端，必要时等待目录同步 |
| 终端面板焦点 | Enter、Tab、方向键、Esc、Ctrl+C、Ctrl+D | 按终端协议交给程序，不触发 AI 快捷键 |
| 菜单/会话列表 | ↑ / ↓、Enter、Home/End | 移动选择、打开；不改变输入历史 |
| 可编辑文本 | Command+C | 复制选中文本；无选区不冒充复制任务结果 |
| 结果气泡焦点 | 复制动作按钮/所标快捷键 | 复制该 Run 结果，不复制其他 Run |
| 任务详情 | 明确“复制完整输出”按钮 | 复制该任务完整可用输出 |
| 全局热键 | 已注册切换键首次 keydown | 主动显示/隐藏；忽略自动重复 |
| 所有 Web 表单 | Tab / Shift+Tab | 按阅读顺序移动；无不可退出的自制焦点陷阱 |

命令键显示由平台格式化；macOS 首版使用 Command/Option 图形，公共契约不保存这些装饰字符作为真实键名。

### 11.3 Esc 优先顺序

从最内层开始，仅一个作用域消费一次 Esc：

1. 输入法正在预编辑：透传输入法，不关闭窗口、提交或取消任务。
2. 快捷键录入：取消录入并恢复注册状态；显式录入 Esc 流程除外。
3. 应用级确认：取消确认，返回打开者。
4. 会话/模型/更多菜单：关闭菜单并归还焦点。
5. 普通任务/结果面板：关闭当前面板，不取消 Run。
6. **终端内容区拥有焦点：**Esc 交给终端程序，不上冒泡执行上述面板关闭或主条隐藏。
7. 主操作栏输入且没有内层面板：作为用户主动隐藏，执行当前 `hideBehavior` 并暂停自动显示。

终端使用清晰的“收起终端”按钮离开显示；不能要求用户用 Esc 退出一个把 Esc 作为业务键的程序。自动淡出、Finder 暂隐和面板关闭均不沿用第 7 条主条隐藏动作。

### 11.4 无障碍与可读性

- 所有图标按钮有明确可访问名称；状态同时使用图形、文字和颜色，绿色 `!` 另有“终端”文字。
- 标题、字段 label、说明和错误建立程序化关联。设置更新、目录同步与任务完成用节制的状态播报；流式每行输出不逐行轰炸读屏。
- 全部交互至少 24×24 逻辑像素命中区；窗口主要动作首选 28–32。即使保持小图形，透明命中区也不得重叠。
- 普通文字对比度以 4.5:1、必要控件/焦点边界以 3:1 为验收目标；透明材质在不同壁纸下验证，不能只在参考壁纸上可读。文字目标参照 [W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，实际达标需在新 UI 实现后测量。
- 系统减少透明度/提高对比度时使用不透明 token；系统减少动态时移除位移/缩放和自动滚动动画，保留静态选中与完成信息。
- 隐藏、退出和不可用的面板从焦点序列移除；动画完成不是解除键盘拦截的唯一时机。
- 重要失败、待批准、目录同步失败不随结果气泡计时消失；在对应列表/表单中持续可访问。
- 终端密码输入遵从程序的回显行为，UI 不另做按键回显或原始输入日志。任务/历史/诊断对应用管理凭据和可识别秘密使用脱敏值；未知程序自行输出的秘密不作全量识别保证。

### 12.4 原生窗口、官方组件与平台材质

2026-09-23 用户试用反馈覆盖旧自绘方案。控制台与设置使用 macOS 原生标题栏 overlay、隐藏标题文字和真实红绿灯，按钮位于侧栏顶部（左 16、上 18 逻辑点），顶部栏高 48；不再叠加网页红绿灯或单独的白色标题行。关闭只销毁视图，宿主常驻；再次打开应用或菜单入口会显示、聚焦控制台。

macOS 以普通 App 启动（LSUIElement=false / Regular），控制台或设置打开时显示 Dock；关闭最后一个管理窗口后转为 Accessory，仅菜单栏常驻，点击应用图标再打开控制台。启动动画遵循系统 Dock 的动画偏好，不人为反复请求弹跳。输入条保留无边框窗口和一个隐藏红点，仍遵循 hideBehavior；手动隐藏时将焦点交回 Finder，不带起后台控制台。Finder 与输入条属于同一交互组，进入其他应用即暂隐，不能恢复到其他应用之上。几何观察使用 WindowServer 元数据（50ms 检查；停止移动、松开鼠标并稳定两轮后恢复），选区读取独立运行；后台刷新不抢焦点。

界面直接采用 shadcn 官方组件，来源为 [Sidebar blocks](https://ui.shadcn.com/blocks/sidebar)，本地源码位于 `packages/ui/src/components/ui/`。控制台/设置共享侧栏、标题栏与内容容器；侧栏 232↔80，折叠后保留可访问名称及图标；按钮、卡片、输入、选择、开关、弹窗复用官方组件。原生拖动区只在非滚动标题背景和输入条背景上，不能截获控件或滚动。

macOS 26+ 的透明模式使用 NSGlassEffectView；macOS 14/15 使用 NSVisualEffectView 回退。系统减少透明度或用户关闭透明材质时使用不透明表面；减少动态立即完成过渡。Windows 保持常规组件表面，不套用 macOS 玻璃 CSS；Windows 的完整原生适配与实机验收仍按后续平台里程碑进行。

模型页提供 OpenAI、DeepSeek、通义千问（北京）、OpenRouter、Ollama、LM Studio 的可编辑连接预设，预设不等于已配置或已可用。保存、密钥处理、连接检查仍由 Rust 服务执行，模型列表以实际端点返回为准。

## 13. 动效规格

### 13.1 数值来源

旧 token 的曲线为 `cubic-bezier(.2,.8,.2,1)`，`feedback=140ms`、`menu=220ms`、`layout=280ms`、`window=320ms`、`composer=520ms`，`collapsedScale=.96`。这些来自 [tokens.json](../Web%20APP/src/motion/tokens.json)，不是视频测得的数据。

新 UI 保留这五种职责与集中式 token。2026-09-23 再次抽取 10.70–11.10s 和 93.80–94.10s 连续帧，核对锚定展开与双页横向过渡；原生窗口淡入时长是平台实现值，不冒充视频测量值。下表是实现默认值；视频只提供所标出的轨迹/顺序证据。初始缩放、时间或曲线需要视觉调整时，在 token 和偏差记录中集中修改，不在组件内部各写一套。

### 13.2 逐项动作契约

| 动作 | 触发与轨迹 | 时长/曲线默认值 | 中断与焦点 | 减少动态 |
|---|---|---|---|---|
| 控件 hover/选中 | 背景/边框/文字变化 | `feedback` 140ms，统一曲线 | 即刻响应，不延迟事件 | 即时状态 |
| 按钮按下 | 可见反馈；控件允许时轻缩到 .97 | `feedback` | 松开/取消恢复，不改变命中区 | 无缩放 |
| 下拉/会话面板 | 官方弹层按锚点过渡；输入条会话面板与任务面板共用左下锚点 | `menu` 220ms | 最终几何先确定；关闭立即 inert，焦点归还不等离场 | 即时显示/隐藏 |
| 任务面板首次打开 | 锚点关联的缩放/淡入；采用视频 10.70–11.10s 意图 | `menu` 220ms；起始 scale .24、左下 48px 锚点为本次实现默认 | 不把视频推定为某套弹簧；反向操作接续当前视觉状态 | 即时最终布局 |
| 任务列表→详情 | 列表向左退出，详情从右进入；返回反向 | `layout` 280ms，统一曲线；视频 93.80–94.10s 支持方向与约略量级 | 退出页立即不可交互，保留滚动恢复点 | 即时切页并显示面包屑 |
| 设置组高度 | 定时/常驻等条件字段改变 | `layout` 280ms | 观察内容自身高度；连续变化合并目标 | 即时高度 |
| 工作区侧栏 | 232↔80 宽度变化 | `window` 320ms | 折叠后保留图标名称和焦点可达性 | 即时宽度 |
| 控制台/设置显示 | 原生淡入，关联主动打开入口 | 180ms；隐藏 100ms，统一曲线 | 原生与 Web 不重复做两次入场 | 即时显示 |
| AI 提交 | 草稿淡出，输入/建议恢复；任务独立启动 | `composer` 520ms 预算，其中编辑区恢复不晚于 320ms；视频 54s 仅验证该顺序 | 不排队播放旧动画；新输入立即取消剩余视觉收尾 | 即时清空并播报已提交 |
| 结果气泡 | 锚定淡入，短结论可读后启动计时 | `menu` 220ms | 悬停/焦点/模态暂停定时；用户关闭即失去交互 | 即时显示 |
| Run 定位 | 滚动至行后背景高亮一次 | `feedback`；高亮保持 600ms 为新默认 | 不循环闪烁、不移动用户正在编辑的面板 | 即时定位+静态边框 |
| Finder 移动暂隐/恢复 | 隐藏依附表面，停止后按最终坐标恢复 | 暂隐即时；恢复可用 `feedback` 淡入 | 不触发会话 hide 策略，不产生跟随拖尾 | 即时 |
| 目录状态 | 真实目录与待切目录文字更新 | `feedback`，只淡入新状态 | 不用长动画延迟事实更新 | 即时 |

spinner 只表示不确定进度；能获得真实百分比时显示真实进度。空闲界面不添加装饰性呼吸、抖动或持续辉光。位移/窗口尺寸由一个负责人驱动，宿主坐标更新和 Web 内容动画不能同时修改同一屏幕位置。

### 13.3 动效验收记录字段

每项动作保留 `motionId`、触发输入、来源截图/时间、起止状态、时长与曲线来源、可中断规则、焦点时机、退出交互规则、减少动态结果。测量时区分真实输入触发、采样中间帧和源码 token；不得把联系表或 CSS 声明本身当成运行时已通过的证据。

## 14. UI 数据契约与事件边界

### 2026-09-20 能力与历史实现补充

能力库按目录展示并支持搜索；选中能力后显示固定工作目录、输入列表与参数。生成计划后定位关联任务，变更按当前策略确认。重复调用已结束能力应重新选择输入与参数。只有真正需要模型的摘要操作才依赖模型端点，缺少本地工具/语言包返回具体原因。

任务页按会话展示执行记录及最近 100 条只读会话内容，摘要回退全文在此保留；结果气泡定位相应任务。历史任务重试新建关联会话，旧执行确认不继承。更早对话分页、完整 PTY 历史回放和精细下载进度仍需补齐，不能计作已验收。

### 2026-09-23 追加：固定看板与统一任务反馈

概览采用占满可用高度的固定看板；六类能力、使用准备、平台状态和工具/转换设置入口在最小 640×520 窗口内完整可达，主内容不纵向滚动。详细记录进入对应页面查看。
