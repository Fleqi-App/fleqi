# Fleqi 开发文档

版本：文档重启基线 · 更新：2026-09-20 · 状态：基础工程已交付；M2–M4 有实现，主要执行阻塞已修复，完整产品仍有工程收尾与条件验收。

Fleqi 是计划以 AGPL-3.0-only 发布的开源通用桌面命令助手。输入条承载日常 AI 与终端交互，工作区是通常隐藏的管理控制台。先交付完整 macOS 版本，Rust 核心和同一 Web UI 通过平台适配延伸到 Windows、Linux。

当前目录中的六份文档是后续开发的依据。开发合同恢复自本地早期快照 `708a566`，清除了旧施工状态；来源见[回退记录](restart.md)。P0 于 2026-09-17、M1 于 2026-09-18 完成；后续实现与原生测试已有交付，但本轮审查发现产品出口仍有阻塞，见[当前状态](status.md)与[项目核查](review-2026-09-20.md)；现有 `Web APP/` 提供两个页面的 UI 参考，不能作为已完成业务功能的证据。

## 本轮已经确定的边界

- 通用桌面命令能力、六类文件处理、AI、工具安装、规则、收藏、持续终端和多会话均属于首版 macOS 范围。
- 用户配置自己的 API、代理地址或本地模型服务；没有 Fleqi 自营代理、订阅、试用、激活或强制账号登录。
- 实时语音属于下一版本；文件转写、字幕和 OCR 仍属于首版能力。
- `activation` 支持 `manual` 与 `followFinder`。自动显示由设置选择，独立于快捷键是否绑定。
- 当前可见会话随 Finder 自动同步目录；终端忙碌时等待安全提示符，后台保留会话不被改目录。
- `hideBehavior` 决定主动隐藏后保留全部或结束全部；Finder 移动的临时隐藏不结束会话。
- 图钉置顶会话及其历史在列表中的位置，删除是独立操作。
- AI 策略仅有 `yolo` 和 `readOnlyAutoConfirmChanges`；手动 `!` 和终端面板输入按普通终端交互。

字段默认值以需求文档中的“设计默认值”为唯一来源，UI/架构中的字段表是映射与呈现合同。

## 编号与变更方式

| 编号 | 含义 |
|---|---|
| `FR-域-序号` | 功能需求 |
| `NFR-域-序号` | 非功能需求 |
| `CAP-域-序号` | 新能力定义 |
| `AC-CAP-序号` | 能力验收 |
| `AC-FLOW-序号` | 跨模块用户流程验收 |
| `UI-名称` | 界面/呈现职责 |
| `ADR-序号` | 架构决定 |
| `M0–M5`、`P0` | P0 位于 M0 与 M1 之间，负责工程准备；M1–M5 交付产品 |

稳定 ID 不因改标题或换实现而重用。需求改变时，在同一变更中更新相关能力、UI、架构、验收和本文日期；新增能力必须有具体输入输出与 AC。延期或删除已经确认的首版能力必须来自新的产品决定，不能借技术排期静默缩水。
