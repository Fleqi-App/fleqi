## What Fleqi does

Fleqi brings AI tasks, manual shell commands, and a persistent terminal into sessions tied to your Finder context. The input bar is the everyday entry point; the workspace holds tasks, capabilities, rules, favorites, tools, and settings. You bring your own model API or local service. See the [English](README_EN.md) and [Chinese](README_CH.md) READMEs for details.

The [0.0.2 Beta release](https://github.com/Fleqi-App/fleqi/releases/tag/v0.0.2) is for macOS 14+ on Apple Silicon. Follow [docs/status.md](docs/status.md) for current progress and acceptance work, and read the [release notes](docs/release-notes/0.0.2.md) before installing.
